# 列表可见序号 + `/` 数字快搜 — 设计文档

日期：2026-09-18  
状态：已与用户确认  
关联：`docs/superpowers/specs/2026-09-03-filter-alias-design.md`（`/` 过滤与 alias 基线）

## 1. 目标与范围

### 目标

1. 在分组 / 项目列表行首渲染 **稳定可见序号**，方便肉眼定位。
2. 过滤串为纯数字时，按该序号 **数值相等** 命中（`/1` 与 `/01` 等价），无需输入名称。

### 非目标（本轮）

- 落盘 `order` 字段、表单/CLI 编辑序号。
- 改变现有列表排序（仍按 `projects.json` 中的现有顺序）。
- 连接 / 回收站 / 工具 / 命令列表的序号或数字快搜。
- Browse 模式免 `/` 直接打字；拼音 / 模糊 / 跨组全局快搜。

## 2. 序号语义

| 列表 | 序号范围 | 基准 |
|------|----------|------|
| 左栏分组 | `1..=groups.len()` | 未过滤时的全部 `data.groups` 顺序 |
| 右栏项目 | `1..=group.projects.len()` | 当前组内、未过滤时的 `projects` 顺序 |

- **1-based**。
- 过滤进行中 **不重编号**：仍显示并匹配上述稳定序号，避免输入过程中目标项序号漂移。
- 与 `alias` 无关；`alias` 仍按现有子串规则匹配。

## 3. 渲染

- 位置：列表文案 **最前**，与名称之间一空格。
- 宽度：至少两位，不足补零；超过两位不截断、不补零。
  - 例：`01`、`02`、…、`99`、`100`。
- 分组示例：`01  Work [wk]  3`
- 项目：在现有 `project_item` 行首同样加序号（保留 path / SSH / alias 等既有片段）。

辅助函数建议（如 `format_list_index(i: usize) -> String`，`i` 为 0-based 下标）：`format!("{:02}", i + 1)`（`i + 1 >= 100` 时自然变三位及以上）。

## 4. `/` 匹配规则

在现有匹配（分组：name / alias；项目：name / alias / path / linux_path / id 前缀）之上增加：

1. 若 `filter` 非空且 **整串为十进制数字**（`chars().all(|c| c.is_ascii_digit())`，且可解析为 `usize`）：
   - 命中条件：该项稳定序号 `==` 解析值（`/1`、`/01`、`/001` 均只命中序号 `1`）。
   - 与名称等规则为 **或** 关系：数字过滤也可因名称碰巧含子串而命中（保持简单；不强制「纯数字时仅走序号」）。
2. 若过滤串 **不是** 纯数字：不参与序号匹配（避免 `/dev` 之类误伤）。

空过滤：行为不变，展示全量列表。

## 5. 实现落点（预期）

| 区域 | 变更 |
|------|------|
| `src/tui/ui.rs` / `widgets.rs` | 分组行、项目行前缀序号 |
| `src/tui/app/filter.rs`（及 `left_items`） | 纯数字 → 稳定下标相等 |
| `src/tui/app/tests.rs` | 见下节 |

不改 `domain` / `persist` schema。

## 6. 测试

- `format_list_index`：`0 → "01"`，`8 → "09"`，`99 → "100"`（下标 99 → 序号 100）。
- 分组：`filter = "1"` / `"01"` 仅命中下标 0；`"2"` 命中下标 1。
- 项目：组内同上。
- 过滤收窄后，被命中项的展示序号仍为未过滤下标对应值。
- 非数字过滤（如 `"wk"`）不因序号逻辑改变既有 alias/name 行为。

## 7. 验收

- TUI 左栏 / 项目列表行首可见至少两位序号。
- `/01` 或 `/1` 能快速定位对应项；Enter 映射选中逻辑与现网过滤一致。
- `cargo test`（含 `tui/app` 过滤相关）、`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`。
